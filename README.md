# media-stick

Raspberry Pi 3B+ как «свисток» для обычного телевизора: Kodi на весь экран, управление с телефона, передача медиа по сети. Всё, что стоит на устройстве, описано в этом репозитории и ставится одной командой.

## С нуля

1. Карта в Mac → `provisioning/make-card.sh disk8` (номер диска: `diskutil list external physical`).
2. Карта в Pi, сеть (кабель или «Общий интернет» Mac), питание.
3. Pi сам клонирует этот репозиторий и запускает `device/bootstrap.sh`. Через 10–15 минут на экране Kodi.

## Каждый день

| что | команда |
|---|---|
| выкатить `main` на устройство | `tools/deploy.sh` |
| выкатить незакоммиченную правку | `tools/deploy.sh --local` |
| здоровье устройства | `tools/doctor.sh` |
| что сейчас на экране | `tools/screenshot.sh out.png` |

## Устройство

| | |
|---|---|
| `provisioning/` | запись карты и файл первой загрузки (`cloud-init/user-data`) — не меняется |
| `device/bootstrap.sh` | приводит Pi к описанному состоянию; повторный запуск безопасен |
| `device/files/` | файлы, которые кладутся на устройство как есть |
| `tools/` | всё, что запускается с компьютера |

## Секреты

В репозитории только имена (`secrets.example.env`). Значения — на устройстве в `/etc/media-stick/secrets.env` (root:media, 0640). Доступ — SSH-ключ, вход по паролю выключен.

Потеряли ключ: положите новый публичный ключ файлом `authorized_keys` в загрузочный раздел карты (FAT, открывается на любом компьютере) — Pi добавит его при старте.
